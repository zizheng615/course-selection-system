## 1. 开场：技术栈与架构（1 分钟）

打开 `README.md`，讲三句话：

1. 功能与参考项目逐项对齐，技术栈换成 Python + FastAPI + SQLite；
2. **零外部依赖** —— 不需要 MySQL、不需要 Node、不需要联网，`pip install` 后三条命令跑起来；
3. 分层是 `Controller → Service → Repository`，**事务边界只在 Service 层**。

打开 `backend/app/main.py`，指出路由注册是一个循环：

```python
for router in ALL_ROUTERS:
    app.include_router(router, prefix="/api")
```

> 「新增一个模块只需要往 `ALL_ROUTERS` 里加一个元素，这个文件不用改 —— 这是第一个开闭原则的落点。」

## 2. 管理员：课程与排课（3 分钟）

登录 `admin`。

### 2.1 课程管理

* 展示列表：分页、关键词搜索、学期与状态筛选。
  点「新增课程」，填一门 `PY301 Python 程序设计`，容量 `50`。
* 讲一句：**列表查的是 `v_course_detail` 视图**，它把教师姓名、职称和剩余容量
  （`capacity - enrolled_count`）一次算好，前端不用做二次查询。

### 2.2 排课 —— 演示「教师时间冲突」★

点「排课管理」，选中刚建的 `PY301`，新增上课时间：

| 字段 | 值 |
|---|---|
| 星期 | 周三 |
| 开始节次 | 1 |
| 结束节次 | 2 |
| 周次 | 1 ~ 16 |

点「添加」→ **被拒绝**，提示「该教师在周三 1-2 节已有其他课程安排，排课冲突」。

> 「`tea001` 张建国老师周三 1-2 节已经在给数据结构上课了。
> 冲突判定用的是**区间重叠**：`A.start <= B.end AND B.start <= A.end`，
> 不是简单的相等比较 —— 所以『第 1-2 节』和『第 2-3 节』也算冲突。」

**注意弹窗没有关闭，刚才填的内容还在** —— 顺手讲这是一个修过的缺陷：
确认回调是异步的，早期版本把 Promise 和 `false` 比较，导致保存失败时弹窗照关、输入丢失。

再演示一次字段校验：把「开始节次」改成 `5`、「结束节次」保持 `2`，
提示「开始节次不能大于结束节次」。

最后改成 **周五 5-6 节**，保存成功。

| 角色 | 欢迎语 | 推荐问题 |

| 管理员 | 你好，系统管理员 | 怎么新增课程 / 怎么排课 / 怎么重置学生密码 / 怎么管理选课记录 / 统计报表在哪里 |
| 教师 | 你好，张建国 | 怎么查看学生名单 / 怎么录入成绩 / 系统有哪些功能 |
| 学生 | 你好，张伟 | 怎么选课 / 为什么有的课选不了 / 在哪看课表和成绩 / 怎么退课 |

然后做**越界测试**：用教师账号问「怎么退课」→ 回答落到 **「未匹配」**。

> 「知识库条目带角色标签，匹配时按角色过滤。越界的问题不编造答案，
> 而是明确说『没把握』并给出本角色能问的问题。」

再问一个正常的「怎么录入成绩」，指出：
* 来源标签是 **「本地知识库」**（区别于「未匹配」和大模型的服务名）；
* 回答里的 `**加粗**` 是**真的渲染**出来的，且**没有使用 `innerHTML`** ——
  > 「目录里任何一个用户输入（课程名、姓名）如果被拼进 `innerHTML`，
  > 而 JWT 又存在 `localStorage` 里，那就是一条完整的 XSS 攻击链。全站零 `innerHTML`。」

**（可选，如果配了 `AI_API_KEY`）** 问一个知识库没有的问题，展示大模型兜底，
来源标签变成配置的服务名。

## 7. 代码讲解：开闭原则的四个落点（2 分钟）

打开 `backend/app/ai/registry.py` 与 `service/ai_service.py`。

```python
class AiService:
    def ask(self, question, ctx):
        for provider in self.providers.available():   # 按 order 依次询问
            answer = provider.try_answer(question, ctx)
            if answer is not None:
                return answer
        return FALLBACK
```

> 「`AiService` 不认识任何具体提供方，它只做编排。
> 新增一个回答来源 = 写一个类实现协议 + 注册一行，**已有文件改动数为 0**。」

补一句：另外三个落点是**路由注册表**、**`require_role` 声明式权限**、
**前端三张注册表**（路由表 / 视图表 / 菜单表）。

**收尾**：运行 `python scripts/run_queries.py` 现场展示三条**一致性自检查询
返回空结果集**（计数与真实记录一致），再运行 `python scripts/sanitize_check.py`
展示脱敏门禁通过。

## 8. 可能被问到的问题

**Q：SQLite 能扛住并发吗？和 MySQL 比怎么样？**

A：本项目用 `BEGIN IMMEDIATE` 显式申请写锁 + WAL 模式 + `busy_timeout`。
关键点是**防超卖不依赖数据库的隔离级别**，而是靠一条带条件的原子 UPDATE：

```sql
UPDATE course SET enrolled_count = enrolled_count + 1
 WHERE id = ? AND status = 'OPEN' AND enrolled_count < capacity
```

只看 `rowcount` 判断有没有抢到。这个写法在 MySQL 和 SQLite 上语义完全一致。
开发阶段用多线程压过：N 个线程抢 K 个名额，成功次数恰好等于 K，
且 `enrolled_count` 与真实选课记录数完全一致（详见 `docs/测试报告.md`）。

**Q：为什么退课不直接删记录？**

A：因为 `enrollment` 上有 `(student_id, course_id)` 唯一索引。
删了行，学生重新选同一门课会撞唯一索引；而且管理员就看不出「谁选过又退了」。
所以退课只改状态，重选时复用原记录并清空旧成绩。

**Q：时间冲突为什么教师只判节次、不判周次？**

A：学生冲突要节次和周次**都重叠**才算冲突（两门课只要不在同一周上就不冲突）。
教师不一样：一位老师在同一个学期的同一天、同一时间段只能出现在一个教室，
哪怕两门课周次不重合（1-8 周和 9-16 周），教务处也无法安排，需要留调课余地。

**Q：前端为什么不用 Vue？**

A：题目要求零外部依赖可运行。用 CDN 引 Vue 需要联网，用 npm 构建需要 Node 环境，
两者都会让「解压即运行」失败。所以前端是手写的原生 ES Module，
由 FastAPI 的 `StaticFiles` 直接托管，并自建了一个小组件层。

**Q：为什么用 hash 路由？**

A：`StaticFiles` 没有 SPA fallback，直接访问 `/admin/courses` 会 404。
hash 路由的内容不会发给服务器，正好绕开这个问题。

**Q：项目里有没有敏感信息？**

A：没有。演示时可以直接跑 `python scripts/sanitize_check.py` ——
它会机械扫描 API Key 字面量、被赋非空值的 `api-key`、硬编码绝对路径，
以及是否有 `.env` 或 `*.db` 混进来，命中任意一条就让打包失败。
`scripts/package.py` 会先跑这个门禁，不通过就产不出压缩包。

**Q：AI 的 Key 放在哪？**

A：只从环境变量 `AI_API_KEY` 读取，仓库里只有 `.env.example` 占位符。
留空时大模型提供方 `is_available()` 返回 `False`，系统自动退化为纯本地知识库 ——
所以**不配 Key 也能完整演示**。
